## Welcome to the API Reference

This API allows you to manage contacts and retrieve conversation data for your AI agents. It uses the OpenAPI specification for defining the API endpoints and request/response structures.

## Authentication

All API endpoints are authenticated using API keys. The `x-api-key` header is required for all requests.

```json
"security": [
  {
    "ApiKeyAuth": []
  }
]
```

## Key Features

*   **Contact Management:** Create, retrieve, update, and delete contacts. Enrich contact data with additional information.
*   **Conversation Retrieval:** Retrieve paginated lists of conversations, filterable by contact ID or agent ID.

## Base URL

The base URL for all API endpoints is `/public-api`.
