## Welcome to the API Reference

This API allows you to manage contacts and retrieve conversation data for your AI agents. It uses the OpenAPI specification for defining the API endpoints and request/response structures.

## Authentication

All API endpoints are authenticated using API keys. Include your API key in the `x-api-key` header with every request.

```bash
curl -H "x-api-key: YOUR_API_KEY" https://agents.nineteen58.co.za/public-api/contacts
```

The API uses the following security scheme:

```json
{
  "securitySchemes": {
    "ApiKeyAuth": {
      "type": "apiKey",
      "in": "header",
      "name": "x-api-key"
    }
  }
}
```

<Note>
  Keep your API key secure and never expose it in client-side code or public repositories.
</Note>

## Base URL

The base URL for all API endpoints is `https://agents.nineteen58.co.za`.
